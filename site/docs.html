For everyone

Getting going

Pango is one program and one file. There is no account to create, nothing to configure before it will start, and no connection required.

01

Try it with demo data

The fastest way to see whether it fits how you work. Nothing is written to disk.

  1. Download the binary for your machine
  2. Run ./pango --demo
  3. Open localhost:8099
  4. Sign in as demo@pango.local / demopassword
02

Set it up for real

One command, one database file. The first account you create becomes the owner.

  1. Run ./pango --db /var/lib/pango/pango.db
  2. Register the first account — this closes registration
  3. Add your buildings
  4. Create further users as an operator
03

Put it where people work

It binds to your own machine only, until you deliberately say otherwise.

  1. Office machine or NAS: --addr 0.0.0.0:8099
  2. Tablets on the LAN reach it directly
  3. Off-site? See cloud & tunnelled nodes
  4. No network at all? A USB stick is a valid transport
